# n00bcodr's Jellyfin Plugins

The manifest repository for:

- [Jellyfin Enhanced](https://github.com/n00bcodr/Jellyfin-Enhanced)
- [JavaScript Injector](https://github.com/n00bcodr/Jellyfin-JavaScript-Injector)
- [Jellyfin Tweaks](https://github.com/n00bcodr/JellyfinTweaks)

## Add this repository to Jellyfin

Dashboard -> Plugins -> Repositories -> Add Repository, and use:

```
https://raw.githubusercontent.com/n00bcodr/jellyfin-plugins/main/manifest.json
```

All three plugins above will then show up in the Catalog, for both Jellyfin 10.11 and Jellyfin 12.
